# projek/

Folder kerja setiap video, dibuat dengan `bash scripts/projek-baru.sh <id-template> "<Tajuk>"`.

```
projek/YYYY-MM-DD_Tajuk/
  BRIEF.md   template, untuk siapa, CTA, skrip, nota revisi
  aset/      footage, audio, gambar, logo
  kerja/     enjin + kod babak + config
  render/    MP4 dan preview
```

Isi folder ni tidak masuk git. MP4 yang lulus dipindah ke Drive `02_Projects/<projek>/04_Siap`.
