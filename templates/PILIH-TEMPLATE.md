# Cara Pilih Template

Jawab soalan ni ikut urutan. Berhenti di jawapan pertama yang padan, kemudian semak soalan 5 untuk alternatif.

## 1. Bahan apa yang Ammar bagi?

| Bahan | Terus ke |
|---|---|
| Klip testimoni penerima/waris | `ads-testimoni` |
| Beberapa klip sedih/kebajikan + QR | `video-emosi` |
| Klip kuliah/ceramah untuk kempen derma | `iklan-kuliah` |
| Klip ceramah/ucapan/avatar Kiara untuk edukasi atau politik | `talking-head-editorial` |
| Klip muka sendiri bercakap (tips) + B-roll | `talking-head-kuning` |
| Klip mentah makan di kedai/kafe | `review-kedai-makan` |
| Fail audio naratif sahaja | `pop-art-audio` |
| Link post rasmi X atau video rasmi syarikat AI | `reel-post-rasmi` |
| Teks berita atau link berita | `berita-3-tema` (tanya tema) |
| Tiada footage, cuma idea atau skrip | teruskan ke soalan 2 |

## 2. Untuk siapa dan tujuan apa? (bila tiada footage)

| Untuk / tujuan | Utama | Alternatif |
|---|---|---|
| airingkas.my, tip step by step | `airingkas-tutorial` | `avatar-tutorial` (kalau nak muka Ammar) |
| Ammarcreava, update AI terkini, landskap | `edukasi-ai-landskap` | `airingkas-tutorial` (kalau nak potret) |
| Promo brand, SaaS, kelas, servis | `kinetik-promo` | `motion-klien` |
| Klien berbayar (sekolah, madrasah, bisnes) | `motion-klien` | `kinetik-promo` |
| Jual ebook/produk digital secara soft sell | `komik-jualan` | `kinetik-promo` |
| Spa Bekam Al Firdaus | `bekam-papercut` | `motion-klien` |
| Isu semasa/politik PAS | `pop-art-audio` (ada audio) atau `berita-3-tema` | `talking-head-editorial` |

## 3. Nisbah

- TikTok, Reels, Shorts, Threads: 9:16.
- YouTube biasa, FB landskap: `edukasi-ai-landskap` atau `kinetik-promo` versi 16:9.

## 4. Bajet kredit

- Paling jimat (0 kredit gambar): template yang lukis semua dengan kod (`komik-jualan`, `pop-art-audio`, `berita-3-tema` Kartun/Sinematik, `bekam-papercut`, `airingkas-tutorial`).
- Guna kredit ElevenLabs: semua yang ada VO ElevenLabs. Gambar AI ElevenLabs mahal, jadi elak kecuali Ammar minta.
- Perlukan shot realistik: cadang Seedance (Axcel Studio) atau Google Flow sebagai tambahan, bukan ganti.

## 5. Format cadangan kepada Ammar

```
Cadangan template untuk "<tajuk>":

1. <ID> (utama): <sebab 1 ayat>. ±<durasi>, <nisbah>.
   Bahan masih perlu: <senarai ringkas atau "semua dah ada">
2. <ID> (alternatif): <sebab 1 ayat>. ±<durasi>, <nisbah>.

Nak guna yang mana?
```

Jangan cadang lebih dari 2. Kalau permintaan tak padan mana-mana template, cakap terus terang dan cadang template terdekat atau bina template baru (kemudian tambah ke KATALOG.md).
