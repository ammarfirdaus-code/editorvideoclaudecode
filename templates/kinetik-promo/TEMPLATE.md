# Promo kinetik explainer (`kinetik-promo`)

Skill rujukan: `video-promo-kinetik-explainer` (arahan penuh langkah demi langkah ada dalam skill ni).

## Format
1920x1080 (boleh versi 1080x1920), ~60s

## Enjin
Tiada enjin tetap lagi. Bina dari spec ni, kemudian simpan enjin pertama dalam enjin/.

Kalau `enjin/` dalam folder ni masih kosong, salin enjin dari lokasi di atas ke sini, commit, dan tukar status dalam `templates/KATALOG.md` kepada "Dalam repo". Jangan commit aset klien, QR atau footage.

## Rupa
- Latar cream #EFEBE4 dengan vignette lembut; babak brand/offer ungu gelap #2A1F7A ke #1B1650 + partikel lime.
- Teks navy #1E1B4B, aksen ungu #5B4BE0, lime #C8E64A, oren #F28C52.
- Tajuk serif tebal (Fraunces/DM Serif Display), italik untuk perkataan emosi; label kecil monospace dalam kotak.
- Caption karaoke dalam pil gelap di bawah: perkataan disebut putih, akan datang kelabu, kata kunci lime.

## Struktur
11 babak: search bar menaip (hook) → grid overload → soalan besar → split berselerak vs langkah 1-2-3 → brand reveal → 3 kad produk → timeline perjalanan → mockup + pil kelajuan → kad keahlian + harga → rangkaian screenshot → logo + tagline (CTA).

## Peraturan khas
- Tiru gaya dan struktur sahaja, jangan guna nama, logo atau gambar dari rujukan.
- Masa perkataan dari transkrip VO jadi jam induk semua animasi.
- Jangan over-claim hasil.

## Semakan akhir
- Contact sheet 6–9 frame dari MP4 akhir, teks tak tutup muka, tiada teks terpotong.
- `ffprobe` ada audio, saiz bawah 30MB untuk hantar.
- MP4 lulus dipindah ke Drive `02_Projects/<projek>/04_Siap`.
