# Iklan dari klip kuliah (`iklan-kuliah`)

Skill rujukan: `video-iklan-kuliah` (arahan penuh langkah demi langkah ada dalam skill ni).

## Format
1080x1920, 30–45s

## Enjin
Ikut skill video-iklan-kuliah (audio_ad.py + HTML).

Kalau `enjin/` dalam folder ni masih kosong, salin enjin dari lokasi di atas ke sini, commit, dan tukar status dalam `templates/KATALOG.md` kepada "Dalam repo". Jangan commit aset klien, QR atau footage.

## Rupa
Tiga sub-gaya (cadang satu):
- A Papercut: kertas kraft, rakaman terkoyak, cut-out berbayang.
- B Tipografi Tebal (terbukti, lalai): Anton gergasi ikut suara, blok hitam/kuning/putih, kilat + gegar.
- C Scrapbook: polaroid, selotep, coretan marker.

## Struktur
0–3s hook → 3–35s 4–6 poin terkuat penceramah → 35–45s CTA QR/link.

## Peraturan khas
- Branding ikut penganjur, bukan @ammarcreava. Sari kata wajib.
- Jangan tambah dakwaan atau statistik. Hadis hanya jika disemak. Kredit nama penceramah.

## Semakan akhir
- Contact sheet 6–9 frame dari MP4 akhir, teks tak tutup muka, tiada teks terpotong.
- `ffprobe` ada audio, saiz bawah 30MB untuk hantar.
- MP4 lulus dipindah ke Drive `02_Projects/<projek>/04_Siap`.
